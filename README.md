# Online Teacher Platform API

AI-powered teaching assistant backend.

## Endpoints
- `POST /api/v1/upload` — Upload and ingest PDF
- `POST /api/v1/query` — Ask questions about PDF
- `POST /api/v1/generate/slides` — Generate presentation
- `GET /api/v1/health` — Health check
